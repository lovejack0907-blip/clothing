# 衣著提案

這是可直接開啟或部署到 GitHub Pages 的單頁網站版本。

## 使用方式
1. 保持 index.html 與 images 資料夾的相對位置不變。
2. 直接雙擊 index.html 可在瀏覽器預覽。
3. 若要部署 GitHub Pages，將整個資料夾內容上傳到同一個 repository。

## 本版內容
- 簡約：8 套
- 街頭：8 套
- 復古：8 套
- 韓系：7 套
- 共 31 張不重複照片
- 季節可複選（OR）
- 有／無外套篩選
- 詳細穿搭 Modal
- 上一套／下一套
- 桌面 3 欄、手機 2 欄
- 最後一排自動置中
